## About Me

I turn raw data into something you can actually use — pipelines, warehouses, queries, dashboards.

Most of my work lives in **Python**, **SQL**, and **PostgreSQL**. I like building end-to-end flows: pull data from an **API**, clean it, load it into a **data warehouse**, and ship it to a **dashboard** where the numbers make sense.

Before diving into analytics, I spent time in **networking** and **software development**. That background helps when debugging pipelines, working on **Linux**, or wiring up **backend APIs** — but the focus now is data.

Outside of code — yeah, I like anime. Not the loud part of my profile, but it's part of how I unwind and stay inspired.
